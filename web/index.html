Connect an Arduino at 9600 baud, or explore with simulated data.

Firmware

Compile and upload a sketch to an Arduino Uno using the normal bootloader.

Install Arduino CLI first, then use Install build tools once. Select the actual Uno port; an unidentified port could be another device. Upload replaces the current sketch. The original sketch can start moving on reset.
